# Kanto asset layout

Kanto-specific runtime art is organized as `assets/<location>/<category>/<file>`. Location folders include Pallet Town, Routes 1, 2, 4 and 5, Viridian City, Viridian Forest, Pewter City, Cerulean City, Sea Cottage, Mt. Moon, and the remaining Kanto towns.

Categories include `town`, `people`, `story`, `region`, `routeinfo`, `battle`, and `drafts`. The full Kanto overview remains at `assets/region/kanto-map.jpg`; shared art stays in Pika.

Route 3 assets are intentionally not moved; its route image, route-info image and combined battle backdrop remain in TheSunphis/Pika. Route 1/2 map attribution is stored in each location's `town/`.
