# Route 1 map attribution

`kanto-route-1-map-art.png` is the original Route 1 map artwork published on the [Pokémon Fire Ash Wiki — Kanto Route 1](https://pokemonfireash.fandom.com/wiki/Kanto_Route_1), downloaded and converted to PNG for use as the source artwork. The wiki states that its community content is available under [CC BY-SA](https://www.fandom.com/licensing).

`kanto-route-1-map.png` adds a labeled title and Fire Ash location notes without changing the source map artwork. It remains in this folder as a legacy reference; the four old “You are here” crops have been replaced by the coordinated request maps described below.

`route-1.jpg` and the four `kanto-route-1-map-{south,middle,bridge,north}.png` files are the Route 1 map and area crops from `requests/route-1/`. The area crops use the request's gold position rings and are not derived from `kanto-route-1-map-art.png`. The request README does not state a separate external source attribution for these files.
